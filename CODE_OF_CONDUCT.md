# Code of Conduct

We are committed to maintaining a respectful and productive environment.

## Expected behavior

- Be respectful and constructive.
- Keep feedback focused on the code and issue at hand.
- Welcome collaboration and learning.

## Unacceptable behavior

- Harassment, discrimination, threats, or abusive language.
- Disruptive behavior in issues or pull requests.

## Enforcement

Project maintainers may remove or reject content that does not align with these standards.
